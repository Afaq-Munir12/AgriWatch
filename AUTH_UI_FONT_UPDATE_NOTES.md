# AgriWatch Auth + Typography UI Update

This package is based on the user's uploaded `update(2).zip` master project.

Changes made:
- Login and signup cards are shorter and vertically centered on desktop.
- Complete Profile uses the same compact auth geometry.
- Signup/detail forms scroll inside the compact card when needed.
- Auth left panel is reduced to a balanced 630px desktop height.
- Global English UI typography changed to Outfit (display) + Manrope (body).
- Urdu UI changed to Noto Sans Arabic for cleaner rendering and better line spacing.
- Urdu headings/body line-height and word spacing were adjusted to avoid overlapping text.
- Home Urdu hero heading receives responsive sizing/spacing improvements.
- Existing authentication, Supabase, Twilio, ML, Farmer/Public/PDMA/Admin portal logic was not changed.
